# Documentation

`docs/` holds project documentation, including game design documents, technical design notes, and development guides. Use it to explain how the game and its supporting workflows are intended to work.

## Architecture Decision Records

`docs/adr/` holds Architecture Decision Records (ADRs): short records of important technical decisions, their context, the alternatives considered, and their consequences. They explain why an approach was chosen so future contributors can understand it.

To write an ADR, copy the [ADR template](adr/0000-adr-template.md) to the next numbered file, starting with `0001-short-title.md`. Replace the guidance under each heading with the details of the decision, and keep `0000-adr-template.md` as the reusable template.
